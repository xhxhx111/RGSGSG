## 一、怎么部署（三步，全程网页操作）

1. **新建仓库**：GitHub → 右上角 `+` → `New repository`
   - 名字随便起，例如 `wenming-deck`
   - 选 **Public**（Pages 免费版需要公开仓库）
   - 勾 `Add a README file`，然后 `Create repository`

2. **上传文件**：进入仓库 → `Add file` → `Upload files`
   - 把本文件夹里的 **`index.html`** 拖进去
   - 下面 Commit changes 点绿色按钮确认
   - ⚠️ **文件名必须是小写的 `index.html`**，不能是 `Index.html`（GitHub Pages 跑在 Linux 上，大小写敏感）

3. **开启 Pages**：仓库 → `Settings` → 左侧 `Pages`
   - Source 选 **`Deploy from a branch`**
   - Branch 选 **`main`**，目录选 **`/ (root)`**
   - `Save`
   - 等 1–2 分钟，页面顶部会出现网址：`https://你的用户名.github.io/仓库名/`

打开那个网址，就是成品。

## 七、常见问题

**Q：上传后打开是 404？**
A：等 1–2 分钟（首次部署要构建）；再检查 `Settings → Pages` 里 Branch 和目录选对了没；确认文件名是小写 `index.html`。

**Q：页面显示但不翻页？**
A：点一下页面空白处让它获得焦点，再按方向键。

**Q：能不能放视频？**
A：当前版本没有视频。若要加，视频必须和 `index.html` 放在同一层目录，用相对路径引用（`<video src="xxx.mp4">`），且单个文件不超过 GitHub 网页上传上限 **25 MB**。

**Q：想改成自己学校的主题色？**
A：打开 `index.html`，最上面 `<style>` 里的 `:root{...}` 就是配色变量，改 `--coral` / `--honey` / `--mint` 等即可全局生效。
